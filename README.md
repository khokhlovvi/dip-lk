# Лизинговые компании — инструмент «Деньги и Право»

Страница для участников «Деньги и Право»: карточки лизинговых компаний, подбор ЛК под запрос клиента, брокеры коммерческой недвижимости, дорожная карта направления.

В репозитории только сама страница, данных здесь нет. Данные отдаются после входа: из Telegram-бота (Mini App) или по личной ссылке, которую выдаёт бот.
